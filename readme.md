# 📊 Crypto Mood Dashboard

A modern and interactive **Crypto Dashboard UI** built using HTML, CSS, and Vanilla JavaScript.

This project simulates a live crypto market interface with dynamic price updates, market sentiment visualization, and a clean SaaS-style UI design.

## 🎯 Project Purpose

This project was created to practice and demonstrate:

- Modern dashboard UI design
- Real-time UI updates using JavaScript
- DOM manipulation techniques
- Responsive layout design
- SaaS-style interface development

---

## ✨ Features

- 📊 Crypto price dashboard UI
- 🔥 Live-like price updates (simulated data)
- 📈 Market mood indicator (Bullish / Bearish / Neutral)
- 🎨 Modern glassmorphism design
- ✨ Smooth hover animations
- 📱 Fully responsive layout
- ⚡ Lightweight Vanilla JS implementation

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox + Grid + Animations)
- JavaScript (Vanilla JS)
- Responsive Web Design
- UI/UX Design Principles
